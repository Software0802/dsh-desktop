# Session Handoff Directory

This directory is the project status index for handing work between sessions.

## Current Handoff

- [2026-09-02 Pi Desktop vertical slice](./2026-09-02-pi-desktop-vertical-slice.md)

## Required Sections

Every dated handoff should record:

- Objective and scope.
- Completed work with file paths where useful.
- Pending work, ordered by priority.
- Blockers and unresolved decisions.
- Verification commands and results.
- Files or repositories intentionally left untouched.
- The next concrete implementation move.

## Maintenance Rules

- Create one dated file when a session establishes a new milestone or changes the next move materially.
- Keep the newest file linked above.
- Mark work as pending until it is implemented and verified; do not use intent as completion evidence.
- Record failures and environment issues instead of silently omitting them.
- Keep this directory project-specific; DSH upstream and Pi documentation remain external references.
